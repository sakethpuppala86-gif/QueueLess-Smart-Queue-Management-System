# QueueLess – Smart Queue & Token Management System

QueueLess is a web-based Smart Queue and Token Management System designed to make queue management easier for customers and staff.

## 🚀 Features

- 🎟️ Customer token generation
- 👤 Customer name, phone number, and service selection
- 📊 Real-time queue status
- 🔊 Staff dashboard
- 📢 Call next customer
- 🔄 WAITING → SERVING → COMPLETED workflow
- ⏱️ Estimated waiting time
- 👥 Waiting queue display
- ✅ Completed customer tracking
- 📱 Customer and staff pages
- 🔒 Phone number validation
- ⚡ Automatic queue updates
